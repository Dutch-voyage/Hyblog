# Quiz feature archive

The blog's quiz feature was removed from the active Astro application on
2026-09-03. Its original source tree is preserved under
`hybrid-blog-app/src/` in this directory so it is not included in normal blog
builds or exposed as a live route.

The archive contains:

- the `/quiz/` and `/quiz/result/` pages;
- quiz questions, scoring, personality types, translations, and fixtures;
- local quiz history and reader-profile storage;
- earlier question-set archives.

The account page remains active, but its quiz-history panel was removed.
